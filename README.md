# SMART ATM – Fingerprint Simulation

## About the Project
SMART ATM is a web-based ATM simulation application developed using HTML, CSS, and JavaScript. It provides card-based login, simulated fingerprint authentication, and various banking operations.

## Features
- Card Login with PIN
- Fingerprint Login Simulation
- Fingerprint Enrollment
- Balance Enquiry
- Cash Withdrawal
- Cash Deposit
- Cardless Deposit with Simulated OTP
- Cardless Withdrawal
- Mini Statement
- Login and Logout
- System Activity Logs

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Explore the ATM features using the demo accounts.

## Project Limitations
- Fingerprint authentication is simulated using text matching.
- OTP verification is simulated.
- Account and transaction information is stored temporarily in browser memory.
- This application is for educational demonstration only.
